## 一、本次改动概述

本次重构落地了对各个选项卡页面专属展示与交互逻辑的深度重制：

1. **【选择目录】页（Page 0）**：
   - 增加**文件体检状态横幅**（Banner），直观高亮提示当前目录状态：
     - 若为纯源码游戏：提示 `✅ 检测到 N 个 .rpy 源码脚本！已就绪，请点击下一步「导入」进行解析。`
     - 若为封包游戏：提示 `⚠️ 发现 N 个 RPA 归档包 / M 个 rpyc 字节码（游戏处于封包状态），请先点击下方「解包+反编译」！`
   - 增加**文件扫描清单树（`QTreeWidget`）**：完整列出所选目录下的所有 `*.rpa`（红标需解包）、`*.rpyc`（橙标需反编译）以及 `*.rpy`（绿标就绪源码）。
   - 保留 `[选择游戏目录]`、`[选择单个 .rpy]` 与 `[解包+反编译]` 按钮。

2. **【导入】页（Page 1）**：
   - 增加**待导入脚本清单与复选框表格（`QTreeWidget`）**：
     - 展示待导入的脚本相对路径、文件大小以及当前导入状态（已导入/未导入）；
     - 每行前面带勾选框，默认全部勾选。
   - 增加精细化导入控制按钮组：
     - `[全选]` / `[全不选]`
     - `[导入勾选的脚本]`：仅导入用户选中的特定脚本文件，便于分批/按需汉化。
     - `[全部导入]`：一键导入发现的所有脚本文件。
   - 底部常驻导入状态摘要标签（展示发现脚本数、已解析文本段落总数、未译数与跳过数）。

3. **【翻译】、【审校】、【导出写回】页**：
   - 保持独立页面容器，按步骤组织专属控件，各选项卡支持无障碍自由切换浏览，各操作按钮根据工程数据状态实时计算置灰/可用保护。
