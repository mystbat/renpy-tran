## 一、本次改动概述

之前界面的所有操作按钮和功能集中在一起，只通过“置灰”控制可用性。
本次重构将顶部五个步骤按钮转换为真正的**向导式多页选项卡（Wizard Pages）**：
1. **[选择目录] 页（Page 0）**：
   - 放置专属引导文案、`[选择游戏目录（推荐）]` 与 `[选择单个 .rpy 文件]` 按钮；
   - 放置 `[解包+反编译]` 按钮，专用于未解包的 RPA / rpyc 游戏。
2. **[导入] 页（Page 1）**：
   - 放置 `[开始解析/导入]` 专属主操作按钮。
3. **[翻译] 页（Page 2）**：
   - 放置翻译专用大进度条与状态统计标签；
   - 放置 `[开始自动翻译]` 与 `[重试失败项]` 专属操作按钮。
4. **[审校] 页（Page 3）**：
   - 放置条目过滤与双栏对照工作台（左侧彩色状态列表、右侧只读/编辑区、快捷键 `A/F/J/K/Ctrl+S`）。
5. **[导出写回] 页（Page 4）**：
   - 放置 `[导出 CSV (人工外部审校)]`、`[从 CSV 导入]` 与 `[事务化写回游戏目录]` 交付操作。

同时：
- **公共常驻区**：顶部步骤导航栏、当前工作区/游戏路径标签、以及底部的运行日志窗口在所有页面全局常驻。
- **状态联动与高亮**：切换选项卡时，当前激活的步骤按钮高亮显示（蓝底白字）；同时根据 `UiState.all_controls()` 实时计算各个页面内按钮的可用性（如无游戏目录时解包与写回置灰，无译文时导出置灰等）。
