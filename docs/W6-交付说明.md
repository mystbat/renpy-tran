## 3. 迁移对齐策略（§10 落点）

- **对话块**：feature = `translate chinese <label>:` 为**分组键**而非唯一主键；同一 label 下多行按
  **块内行序 FIFO** 对齐（W2 设计中 feature 不可作主键，W6 严格按此实现）。
- **字符串块**：feature 恒为 `translate chinese strings:`，无法用 feature/顺序区分；改为**按原文文本匹配**
  （2.0 仅存 `old "X"` 行，映射到 3.0 的 `new "X"` 段）。2.0 的 `old "X"` 引用行正确保持 `PENDING`，不误判为 `FAILED`。
- **未匹配**：可译段无对应译文 → `FAILED` 且写 `error` 原因，供人工核查；真实数据实测 0 FAILED。
- **熔断**：`_finalize` 调用 `evaluate_export_fuse(match_rate=...)`，< 0.95 抛 `ExportBlocked`。

## 5. 偏差与契约变更建议（需总控裁决）

> 冻结契约（`models.py`/`config.py`/`interfaces.py`）本会话**未修改**。

1. **W5 Exporter 扩展正式化（ADR-0010，已接受）**
   W5 以「可选关键字参数 / 附加方法」形式实现的 `export_rpy_forced` / `write_back_project` /
   `bulk_accept(add_exempt=)` 在 W6 被 CLI 正式消费。本 ADR 将其确立为工程约定：
   冻结 `interfaces.Exporter` 四方法签名不变，扩展一律走「可选 kwargs + 附加方法」且向后兼容。
   当前实现满足该约束（新参数均有默认值）。

2. **CLI 子命令扩展（非冻结文件）**
   新增 `migrate` / `export-csv` / `import-csv` / `ui` 四个子命令于 `pytran/cli.py`（非冻结）。
   其中 `migrate` 为 W6 迁移入口；`export-csv`/`import-csv`/`ui` 把 W5 已落地的 CSV 往返与
   图形审校暴露给终端用户，README 据此编写，保证文档与实现一致。

3. **README 受众定位**
   重写面向非程序员，含「概不负责」免责声明（与约束「README 不携带超越『概不负责』的法律承诺」一致）。
   所有命令示例均经 CLI 解析器实测（8 子命令全部注册成功）。

4. **git 历史清理脚本**
   `scripts/clean_git_history.ps1` 仅提供**演练 + 显式确认**两态，默认不改写历史；
   清洗目标与 `.gitignore` 敏感项对齐（`config.ini` / `*.rpy*` / `archive/**` 等）。
   实际执行需用户自担风险（重写历史、需强推、需先备份）——脚本顶部已显著警告。
