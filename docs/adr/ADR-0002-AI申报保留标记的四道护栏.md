# ADR-0002：AI 申报保留标记的四道护栏

- 日期：2026-10-09
- 状态：已接受（护栏 4 口径经 ADR-0006 修订）
- 影响范围：W2 protocol（§5.4）、W3 engine、W5 ui（人工裁定队列）

## 背景

让 AI 在重试时申报「无需翻译」能解决 target==source 的语义歧义、加速收敛，
但标记可能成为模型「逃翻译」的后门：最需要偷懒的长难句正是最会被申报的句子。

## 决策

采纳申报标记（JSON 字段 `k`/`r`），但加四道护栏：
1. 申报 ≠ 放行：置 `keep_declared` 进人工裁定队列，绝不自动 PASS；
2. 一致性：仅 `t == source`（或空）时接受；标记却改文本 → 按 UNTRANSLATED 拒绝；
3. 归一化：`k` 接受 `1/true/"keep"` 变体，未知变体按普通文本处理；
4. 申报率异常闸：**双口径，经 ADR-0006 修订**——单批降级需「申报率 > `keep_declare_rate_limit`（默认 0.15）且批内样本 ≥5」；样本 <5 的小批次不降级但计入项目级累计计数器，累计口径（≥20 样本且超率）触发全局告警与降级模式。

注入时机：仅重试轮的小请求；首轮提示词保持最简。

## 理由

- 检测层做词法判定、AI 做语义判定，两者互补；但终止论证只依赖检测层（纯函数），
  申报信号不参与终止证明，因此其不确定性不威胁收敛；
- 人工裁定沉淀到豁免表（跨会话学习）后，申报使用频率自然下降。

## 后果

- W3 引擎需新增 `keep_declared` 状态与人工裁定队列的路由；
- W5 审校页需支持裁定「保留原文」（短语入豁免表）与「该翻」（重译），并提供批量全部接受（含撤销）。
