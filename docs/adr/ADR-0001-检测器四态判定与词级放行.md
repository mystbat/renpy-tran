# ADR-0001：检测器四态判定与词级放行

- 日期：2026-10-09
- 状态：已接受
- 影响范围：W2 validators/protocol（§5.3）、W3 engine

## 背景

漏翻闭环（§5.3）要求「直到没有漏翻为止」，若判定不清会产生两类不收敛：
误报行（合法英文如人名、拟声词）永远翻不动；真漏翻行盲试死循环。

## 决策

检测器对每行输出四态：`PASS / UNTRANSLATED / RESIDUAL / EMPTY`。
放行判定固定顺序：剥标签/插值/转义 → 词级白名单匹配（术语表优先）→ 计算残余 → 按残余下结论。
放行粒度是**词/短语**，行的结论由**残余**决定：整行合法英文 → PASS 不入队；混合行仍入队。

## 理由

- 检测是纯函数，客观、可单测，终止保障由此构造性成立（§5.3 论证）；
- 词级而非行级：行级放行会放过「Ian said hello」这类混合漏翻行；
- 语义歧义（模型为何原样返回）不在此层解决，交给 §5.4 AI 申报。

## 后果

- 白名单外的合法英文会先入队、由重试/申报/人工三路消化——首次误报不可避免，但经 §5.4 跨会话学习沉淀后逐项目减少；
- 检测器必须无状态（白名单作参数传入），W2 实现时注意。
