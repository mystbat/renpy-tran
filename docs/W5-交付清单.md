## 5. 偏差与契约变更建议（需总控裁决）

> 冻结契约（`models.py`/`config.py`/`interfaces.py`）本会话**未修改**。

1. **`Exporter` 协议扩展（契约变更建议，ADR 待总控分配编号）**
   冻结 `Exporter` 四方法签名为无 fuse 覆盖 / 无 write_back / 无 add_exempt 参数。W5 需「强制绕过熔断」与「事务化写回」能力，已以**临时扩展**落地：
   - `export_rpy_forced(project, work_dir, *, write_back=False, journal=None)`
   - `write_back_project(project, work_dir, journal)`（委托 `UnrenImpl.write_back`）
   - `bulk_accept(project, uids, journal, *, work_dir=None, profile=None, add_exempt=False)`
   建议：后续由总控在 `interfaces.py` 正式扩充 `Exporter` 协议并补 ADR；当前实现向后兼容（新参数均为可选）。

2. **`include_errors` 通道（W3 遗留裁决）**
   引擎内层 `include_errors`（§5.3 第1次定点升级标志）仍为 noop 记录+日志，壳层未开启。W3 总控裁决明确「留待 W5 契约扩展」，本次未作突破——属已知缺口，已在 `engine.py` 注释与本说明标注。

3. **解包/反编译工作目录**
   遵循 W4b 备注「反编译工作目录应引至 `logs/` 而非游戏目录内」，由 `UnrenImpl` 既有实现保证；`cli.py` 未额外改动游戏目录结构。

4. **§9 真实窗体交互**
