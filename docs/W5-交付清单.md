## 5. 偏差与契约变更建议（需总控裁决）

> 冻结契约（`models.py`/`config.py`/`interfaces.py`）本会话**未修改**。

1. **`Exporter` 协议扩展（契约变更建议，ADR 待总控分配编号）**
   冻结 `Exporter` 四方法签名无 fuse 覆盖 / 无 write_back / 无 add_exempt 参数。W5 已以**可选参数扩展**临时落地（`export_rpy_forced` / `write_back_project` / `bulk_accept(add_exempt=)`），向后兼容。建议总控在 `interfaces.py` 正式扩充并补 ADR。

2. **§9 L483 设置对话框（本收尾补全，契约零改动）**
   原 W5 交付的 `ui.py` 设置对话框仅覆盖 API Key/模型地址/模型名/SDK 目录/语言（漏 §9 L483 的「模型参数（fallback_model/max_tokens/temperature/top_p）、并发数、预算上限」）。本次**在不改冻结 `Config` 的前提下**补全：对话框新增 6 个字段；ADR-0004 仍保证 `api_key` 不落盘；数值字段经 `_coerce_setting` 收敛为 `int/float` 并写入 config.ini 对应 section。复用既有 `Config` 全部字段，无需契约变更。

3. **§9 未配置模式 provider 修复（本收尾）**
   原 `_current_config`/`_build_default_deps` 在空 Key 时急切构造 `OpenAIProvider` 会抛 `OpenAIError`（被 071bbbb 的「未配置模式」部分规避但 `_current_config` 未改）。本收尾：
   - `_current_config` 改用 `build_deps(work_dir, allow_missing_provider=True)`；
   - 用户填 Key 保存后，`_apply_settings` 通过 `_build_default_deps(api_key=...)` 注入**运行时 Key** 重建依赖（因 Key 不入文件，回读空文件会再次触发 OpenAIError）。
   属缺陷修复，未改冻结契约。

4. **`include_errors` 通道（W3 遗留裁决）**
   引擎内层 `include_errors`（§5.3）仍为 noop；壳层未开启。W3 总控裁决「留待 W5 契约扩展」，本次未突破——已知缺口。

5. **解包/反编译工作目录**
   遵循 W4b 备注，反编译输出落 `logs/`（由 `UnrenImpl` 保证）；`cli.py` 未改游戏目录结构。

6. **§9 真实窗体交互**
   `ui.py:run()` 需显示环境，标 `pragma: no cover`；可测逻辑（`UiState`、事件桥、设置对话框纯逻辑）已由 `test_ui_state.py`/`test_ui_smoke.py`/`test_ui_settings.py` 覆盖。GUI 冒烟清单见 §6。
